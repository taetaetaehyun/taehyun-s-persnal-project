# 공정자료 정합성 검사기

PFD · Control Plan · PFMEA · Error Proof 대장 4종 Excel 파일을 올리고 기준 자료를 고르면,
나머지 자료에서 **공정 / 관리항목 / E/P 표기**가 기준과 다른 곳을 셀 위치와 함께 알려 주는 단일 HTML 프로그램입니다.

## 사용법

1. `index.html`을 브라우저(Chrome / Edge)로 엽니다. (JSZip을 CDN에서 불러오므로 첫 실행 때 인터넷이 필요합니다.)
2. 각 칸에 Excel(.xlsx)을 올리거나 4개 파일을 한꺼번에 끌어 놓습니다. 파일명과 내용으로 종류를 자동 분류합니다.
3. 카드의 **기준** 스위치로 기준 자료를 고릅니다. (예: 새 리비전 PFD + Error Proof → CP, PFMEA 비교)
4. E/P 대장 카드에서 비교할 품목을 고릅니다. 제품명 약자(예: SENSOR-AUTO DEFOG → `ADS`)는 자동으로 선택됩니다.
5. 결과 탭
   - **수정 목록**: 문서 · 공정 · 고칠 위치(시트!셀) · 현재 · 기준 · 수정 가이드. 필터, 검색, CSV 저장, Excel 붙여넣기용 복사 지원
   - **공정 매트릭스**: 기준 공정 순서대로 각 문서의 공정명 · 항목 수 · E/P 표기 비교
   - **공정별 상세**: 한 공정의 관리항목을 문서별로 나란히 보고 누락/차이를 색으로 표시
   - **공정 매핑**: 자동 연결이 틀린 공정이나 E/P 항목을 직접 기준 공정에 연결 (결과 즉시 재계산)

파일은 브라우저 안에서만 읽으며 외부로 전송하지 않습니다.

## 기준 결정 규칙

| 비교 | 기준 문서 |
|---|---|
| 공정 · 관리항목 | 기준으로 고른 문서 중 PFD → CP → PFMEA 순으로 첫 번째 |
| E/P 표기 | E/P 대장이 기준이면 E/P 대장, 아니면 E/P 표기가 있는 기준 문서(CP → PFD → PFMEA) |

기준으로 고른 문서가 둘 이상이면, 우선순위가 낮은 기준 문서도 비교해 "기준 간 차이"로 표시합니다.

## 검사 항목

- **공정**: 공정 누락, 기준에 없는 공정, 공정번호 불일치, 공정명 불일치/표기 차이, 공정 순서
- **관리항목**: 누락, 표현 차이(유사 항목), 제품특성/공정특성 열 구분 차이, 기준에 없는 항목(참고)
  - PFMEA는 요구사항 · 고장형태 · 원인 · 예방/검출관리 문구까지 함께 비교합니다.
- **E/P**
  - CP: 셀 위에 올린 `<E/P>` 도형(텍스트 상자)과 셀 안의 `E/P` 문구를 모두 인식. 누락, 기준에 없는 표기, **표기 위치(행) 불일치**
  - PFMEA: 예방/검출관리의 `error-proof`, `E/P`, `실수방지`, `poka-yoke` 문구 유무
  - E/P 대장: 설치 공정명 괄호 안 번호(`(A20)`)와 공정명으로 기준 공정에 자동 연결

## 다른 양식에 쓰는 법

머리글 문구(예: `Process No`, `Process Name`, `Product`, `Process`, `Requirement`, `등록NO`, `설치 공정명`, `검출대상`)로
시트와 열을 자동 인식합니다. 인식이 틀리면 카드의 **시트·열 설정**에서 시트, 데이터 시작 행, 각 열을 직접 지정하세요.
"검사 기준 설정"에서 유사도 기준, 비교에서 뺄 항목(예: Nonconforming product), PFD에서 건너뛸 행(예: Labeling)을 바꿀 수 있습니다.

## 한계

- `.xls`(구 형식)은 읽지 못합니다. Excel에서 `.xlsx`로 저장 후 사용하세요.
- 항목 비교는 단어 유사도(영/한 유사어 사전 포함) 기반이므로, "표현 차이"와 "참고" 항목은 사람이 최종 판단해야 합니다.
