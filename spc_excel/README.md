# SPC Chart 엑셀 (자동 작성)

`SPC_Chart_자동.xlsx` 는 공용 폴더의 두 CSV 를 읽어 SPC Chart 시트를 자동으로 채웁니다. 엑셀 2016 이상, 매크로 없음.

```
공용 폴더\2026\
 ├─ 공정능력_결과기록.csv     ← HTML [결과 저장] (결과 1건 = 1줄)
 ├─ 공정능력_측정데이터.csv   ← HTML [결과 저장] (측정값 1개 = 1줄)
 ├─ 그래프\*.png              ← HTML [결과 저장] (기록 보관용)
 └─ SPC_Chart_자동.xlsx       ← 이 파일 (파워 쿼리로 두 CSV 를 읽음)
```

## 처음 한 번 설정
파일 안 **'설정 안내'** 시트에 순서와 붙여넣을 파워 쿼리 코드가 있습니다.
1. 결과기록 쿼리 → '결과기록' 시트 A1 에 표로 로드
2. 측정데이터 쿼리 → '측정데이터' 시트 A1 에 표로 로드
3. 두 쿼리 속성: '다음 간격으로 새로 고침 1분', '파일을 열 때 데이터 새로 고침'

## 사용
- 'SPC Chart' 시트 C3(노란 칸)에서 기록ID 선택. 비워두면 가장 최근 기록.
- 측정 Data 표(최대 30 Lot × 20개), 평균(X)/범위(R)/관리 상태, 통계치 Summary, 히스토그램, Xbar / R Chart 가 자동으로 바뀝니다.
- 통계값과 관리한계는 HTML 이 계산해 CSV 에 저장한 값을 그대로 씁니다 (Minitab 과 같은 계산).

## 시트
| 시트 | 내용 |
|---|---|
| SPC Chart | 보고서 화면 |
| 계산 | 선택한 기록의 값, Lot 별 평균·범위, 차트용 데이터 (수정 금지) |
| 결과기록 / 측정데이터 | 파워 쿼리가 CSV 를 불러오는 곳 (수정 금지) |
| 설정 안내 | 처음 설정 방법과 파워 쿼리 코드 |

## 다시 만들기
`python3 make_spc_template.py SPC_Chart_자동.xlsx` (openpyxl 필요). 표시 Lot 수·행 수 등은 스크립트 위쪽 상수로 바꿀 수 있습니다.
